# WYF 个人作品站

个人作品展示站，聚焦 **AI 应用导演 × 上下文压缩 × 智慧税务实践**，展示个人定位、能力地图、项目作品、文章方向与合作入口。

## 项目定位

这个网站面向对 AI 落地、财税智能工具、政务数据治理和可视化应用感兴趣的访问者，重点说明：

- 我如何把复杂业务问题压缩成 AI 可执行的上下文
- 我如何调度 AI 编程工具、RAG、智能体、数据大屏和部署工具完成系统原型
- 我做过哪些 AI / 数据 / 内网交付相关实践
- 我能把哪些问题推进成可运行、可展示、可部署的智能应用

## 功能特点

- 深色科技风个人首页
- “AI 应用导演”个人定位与角色标签
- 从业务到系统的能力地图
- AI × 智慧税务项目作品集
- 项目状态、脱敏标识与项目价值说明
- 上下文压缩、AI 协同编排、原型搭建与部署交付能力展示
- 文章方向占位入口
- 合作方向与联系方式
- 响应式布局与移动端菜单
- Framer Motion 动效与 reduced motion 适配

## 技术栈

- React
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## 本地运行

```bash
npm install
npm run dev
```
